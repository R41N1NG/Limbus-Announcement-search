# 边狱公司公告查阅库

Steam官方公告与都市零协会中文公告的个人查阅索引，非官方网站。

## 来源与署名

官方公告来源：Project Moon / Steam。中文译文来源：都市零协会（Localize Limbus Company）及对应B站文章作者。各条目保留来源链接，内容权利归原权利人所有。

本包不包含定时更新任务；当前为本地公告库的静态发布版本。后续更新网页时需重新上传。

## 发布

将本文件夹内的文件上传到仓库根目录，再进入 Settings → Pages，选择 Deploy from a branch、main、/(root)，保存。

## 查询记录

筛选记录只保存在访问者的浏览器中，不上传到服务器。
